# Changelog

## v0.5 — 2026-11-02

- Fix panel interaction by including the UI layer in both XR raycast masks and assigning runtime UI graphics to that layer.
- Add index-trigger click/drag guidance to the spatial panel.
- Add a UI ray regression harness covering 15 routed input checks.
- Publish a reproducible Unity source project, Windows deployment helpers, and Quest installation assets.
- Preserve existing official Touch Plus models, grip alignment, closer workspace placement, and stereo-aware pointer rendering.

The release name was consolidated from the preceding v0.4.4 fix build to v0.5; interaction behaviour is identical. Android version name is `0.5`, version code is `9`. Headset acceptance and demonstration upload are pending.
